Projects / 실시간 화면 검열 시스템

SYSTEM
ARCHITECTURE

본 문서는 실시간 화면 검열 시스템의 데이터 흐름과 모듈별 구성을 기술합니다. Python 기반 프로토타입의 성능 한계를 극복하기 위해 C# .NET 환경으로 리팩토링되었으며, GPU 가속을 통한 실시간 추론 최적화에 중점을 두었습니다.

▲ 시스템 파이프라인 흐름도 (Capture → Process → Inference → Overlay)

01. High-Speed Capture

Win32 API (GDI+, BitBlt)를 직접 호출하여 Windows OS의 화면 데이터를 최소 지연 시간으로 획득합니다. 멀티 모니터 환경을 지원하며, 초당 60프레임 이상의 캡처 성능을 유지합니다.

02. ONNX Runtime Inference

학습된 YOLO 모델을 ONNX Runtime으로 변환하여 실행합니다. NVIDIA CUDA 및 DirectML 가속을 지원하여, 하드웨어 사양에 맞춰 최적화된 GPU 추론 환경을 자동으로 구성합니다.

03. Intelligent Object Tracking

단순 탐지를 넘어 SortTracker 기반의 객체 추적 알고리즘을 적용했습니다. 탐지된 객체에 고유 ID를 부여하여 프레임 간 끊김 없는 연속적인 검열 처리가 가능합니다.

04. Transparent Overlay Rendering

검열 결과(모자이크)를 사용자 화면 최상단에 투명 오버레이 레이어로 렌더링합니다. 시스템 리소스 점유율을 최소화하기 위해 비트맵 메모리 재사용 로직을 포함하고 있습니다.
